# FORMA — Laboratorio geométrico

Aplicación interactiva en español para explorar triángulos, sus medidas y sus construcciones geométricas.

## Explorar

- Elige un triángulo libre, equilátero o rectángulo.
- Arrastra los vértices o usa las flechas del teclado.
- Activa la altura, la mediana, la bisectriz o la circunferencia circunscrita.
- Observa cómo cambian el área, el perímetro, los lados, los ángulos y el centroide.
- Activa o silencia los tonos breves de interacción desde el control de sonido.

## Abrir

Abre `index.html` en un navegador moderno. No requiere instalación ni dependencias.

La interfaz se adapta a móvil y escritorio. Las fuentes de Google Fonts son opcionales y cuentan con alternativas locales.
